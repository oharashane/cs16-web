# Demos

GoldSrc `.dem` recordings — a player's own (POV) or HLTV's — dropped here or uploaded on
`/demos`. The relay lists them with what each file says about itself (the server, the
recorder, the map, everything the server precached and which of it we lack), keeping a
`<name>.dem.json` sidecar beside each file so a listing is instant. `/demos/<name>` plays
one in the game itself, first person, with pause, speed, a scrubber and — for HLTV — the
perspective. Protocol 46, 47 and 48 recordings all open. Nothing here is committed.
