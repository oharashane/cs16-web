Counter-Strike 1.6, in a browser

A family server for the 2003 game, and a museum growing out of it. The whole game — engine, maps, models — runs in the browser tab; nothing to install. Pick a name, pick a resolution, join.

Play Take the tour

Works from anywhere — no VPN, nothing to forward. The first visit downloads about 230 MB of game files and keeps them; later visits are seconds. Chrome, Firefox and Safari all work. On a Retina iMac leave the resolution at 1×.

How it works

Three pieces. The game server is the ordinary Half-Life dedicated server that ran every CS 1.6 server for twenty years, in a container. The client is the open-source Xash3D engine compiled to WebAssembly, with the Counter-Strike game code on top. Between them a small relay turns the browser's WebRTC packets into the UDP the server expects. Native Steam clients join the same server too. The tour's "This project" chapter draws it; the review explains it.
