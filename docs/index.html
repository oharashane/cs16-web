Counter-Strike 1.6, in a browser

A family server for the 2003 game, running on the machine in the study. The whole game — engine, maps, models — runs in the browser tab; nothing to install. Pick a name, pick a resolution, join.

Play

The first visit downloads about 130 MB of game files and unpacks them; later visits are faster. Chrome, Firefox and Safari all work. On a Retina iMac leave the resolution at 1×.

How it works

Three pieces. The game server is the ordinary Half-Life dedicated server that ran every CS 1.6 server for twenty years, in a container. The client is the open-source Xash3D engine compiled to WebAssembly, with the Counter-Strike game code on top. Between them a small relay turns the browser's WebRTC packets into the UDP the server expects. Native Steam clients can join the same server too.

The modes

One server, one mode at a time, changed from the console: classic (buy menu, rounds, bombs and hostages), fun (small arena maps), team deathmatch and free-for-all deathmatch (instant respawn, pick a gun), gungame (a new gun per kill), and scoutz (low gravity, scouts only). Ask whoever runs the house for the password.

Where it is going

The plan is a museum: hundreds of maps and models from the game's first decade, each on a page with a preview and its history, and a server you can start from any of them. The thinking behind that is written up in the review.
